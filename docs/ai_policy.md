# AI Policy

If you are planning to send us AI-generated code, then stop and read this file carefully.  
As I consider programming as an **art** and I give value to code when it is **handwritten**, I **wont accept changes** containing AI-generated code. The same rule applies to **documentation**, **comments** and **reviews**.  
Do not try to bypass this rule!  
If you do not understand something in the code or you do not have enough skills to do something, then just ask for help to **humans**.
