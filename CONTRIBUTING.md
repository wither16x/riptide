# Contributing

Contributions are welcome!

Before doing anything, please read in order:
* [The prerequisites](/docs/prerequisites.md)
* [The AI policy](/docs/ai_policy.md)
* [The coding style](/docs/coding_style.md)

To add your own changes:
1. Fork this repository.
2. Create a new branch. Its name should tell us what your changes are about.
3. Add your changes. Make sure to test everything!
4. Submit a pull request with a detailed description of your changes. Explain the choices you made.
